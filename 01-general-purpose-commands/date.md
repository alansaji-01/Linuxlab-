# Q1. Explain the date command.

**Purpose:** Displays or sets the system date and time. Setting the clock generally requires administrator privileges.

```bash
date
date "+%d-%m-%Y"
date "+%H:%M:%S"
date "+%A, %d %B %Y"
date -u
```

Format symbols: `%d` day, `%m` month, `%Y` year, `%H` hour, `%M` minute, `%S` second, `%A` weekday.
