# Additional Linux Commands

These commands supplement the commands covered in the main sections.

## 1. `man` – display the manual

**Question:** How do you view the manual page of a Linux command?

```bash
man ls
```

Press `q` to quit the manual viewer.

## 2. `history` – display command history

**Question:** How do you display previously executed commands?

```bash
history
history 10
```

The second command displays the most recent ten history entries.

## 3. `file` – identify file type

**Question:** How do you identify the type of a file?

```bash
file filename
```

## 4. `ps` – display processes

**Question:** How do you display the processes running in the current terminal?

```bash
ps
ps -ef
```

`ps -ef` displays processes in a full-format listing.

## 5. `time` – measure execution time

**Question:** How do you measure how long a command takes to execute?

```bash
time ls -l
```

## Quick revision

| Command | Purpose |
|---|---|
| `man` | Read command documentation |
| `history` | Show command history |
| `file` | Identify file type |
| `ps` | Display process information |
| `time` | Measure command execution time |
