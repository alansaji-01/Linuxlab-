## Run the example scripts

From the repository root:

```bash
bash 07-additional-linux-topics/scripts/fibonacci.sh
bash 07-additional-linux-topics/scripts/prime-check.sh 17
bash 07-additional-linux-topics/scripts/palindrome.sh  madam
bash 07-additional-linux-topics/scripts/reverse-number.sh 12345
bash 07-additional-linux-topics/scripts/menu-calculator.sh
bash 07-additional-linux-topics/scripts/read-file-lines.sh 07-additional-linux-topics/sample.txt
```

All scripts are written for Bash. Some commands and options may differ across Linux distributions. Use `man command` to read the manual for a command.
