# Shell Programming Practice

The following are additional common shell-programming practical questions. Each question has a corresponding runnable script in the `scripts/` directory.

| No. | Practical question | Script |
|---:|---|---|
| 1 | Write a shell script to generate the Fibonacci series. | [fibonacci.sh](scripts/fibonacci.sh) |
| 2 | Write a shell script to check whether a number is prime. | [prime-check.sh](scripts/prime-check.sh) |
| 3 | Write a shell script to check whether a string is a palindrome. | [palindrome.sh](scripts/palindrome.sh) |
| 4 | Write a shell script to reverse a number. | [reverse-number.sh](scripts/reverse-number.sh) |
| 5 | Write a menu-driven calculator using the `case` statement. | [menu-calculator.sh](scripts/menu-calculator.sh) |
| 6 | Write a shell script to read and display a file line by line. | [read-file-lines.sh](scripts/read-file-lines.sh) |
| 7 | Write a shell script to print a right-angled star pattern. | [star-pattern.sh](scripts/star-pattern.sh) |
| 8 | Write a shell script to search for an element in an array. | [array-search.sh](scripts/array-search.sh) |

## Running scripts

Run a script from the repository root using:

```bash
bash 07-additional-linux-topics/scripts/fibonacci.sh
```

For scripts that accept arguments, provide them after the filename. For example:

```bash
bash 07-additional-linux-topics/scripts/prime-check.sh 17
```

All scripts include the complete practical question as a comment at the top.
